# Changelog

The authoritative, append-only change history for this project is
**[`docs/43-CHANGELOG.md`](docs/43-CHANGELOG.md)** — it records documentation changes,
ADR/CR outcomes and, once implementation begins, product releases. It is not duplicated
here, because a second copy is the one that drifts.

This file exists because the repository structure requires it, and it marks the point at
which product releases will be summarised for readers who do not work in `docs/`.

## Product releases

No releases yet. The repository currently contains the **scaffold** (mandated structure,
tooling, configuration and a running health-check skeleton). Domain features begin in
Phase 2 of `docs/40-IMPLEMENTATION-PLAN-AND-PHASES.md`, once their owning documents reach
`Approved`.
